# 常见问题

## 连接问题

### 无法连接到代理

**症状**: 客户端报告 `Connection refused` 或 `ECONNREFUSED`

**解决方案**:

1. 确认代理正在运行
   ```bash
   python run.py
   # 应该看到: Kiro API Proxy v1.7.1
   #             http://localhost:8080
   ```

2. 检查端口是否正确
   - 默认端口是8080
   - 如果更改了端口，也要更新客户端配置

3. 检查防火墙
   - Windows: 允许Python通过防火墙
   - macOS: 系统偏好设置 → 安全性与隐私 → 防火墙

### 401认证失败

**症状**: 请求返回401未授权

**原因**: 令牌过期或无效

**解决方案**:

1. 点击账户卡片上的"刷新令牌"
2. 如果刷新失败，重新登录获取新令牌
3. 检查账户状态是否为活跃

## 请求问题

### 429请求过多

**症状**: 请求返回429错误

**原因**: Kiro有请求速率限制

**代理自动处理**:

- 将账户冷却5分钟
- 自动切换到其他可用账户
- 冷却结束后自动恢复

**建议**:

- 添加多个账户以分散请求
- 避免短时间内请求过多
- 在"监控"页面检查配额状态

### 对话过长（CONTENT_LENGTH_EXCEEDS_THRESHOLD）

**症状**: 请求返回 `输入过长` 错误

**原因**: Kiro API有输入长度限制

**代理自动处理**:

内置历史消息管理，可在"设置"中配置：

1. **自动截断** - 优先保留最近的上下文，必要时截断
2. **错误重试** - 收到长度错误时自动截断并重试（默认启用）
3. **预估计** - 估计令牌数，超过则预先截断

推荐: **错误重试**（默认）或 **自动截断+预估计**

**手动解决**:

1. 在Claude Code中输入 `/clear` 清除对话历史
2. 清除后，告诉AI您在做什么
3. AI将读取代码文件以恢复上下文

## 令牌问题

### 令牌过期

**自动处理**: 代理自动检测并刷新令牌

**手动处理**:

1. 点击账户卡片上的"刷新令牌"按钮
2. 如果刷新失败，refresh_token也已过期
3. 需要重新登录获取新令牌

### 如何添加多个账户

**方法1: 多次在线登录**

1. 使用不同的Google/GitHub账户
2. 每次登录自动添加新账户

**方法2: 扫描令牌**

1. 在Kiro IDE中使用不同账户登录
2. 每次登录后点击"扫描令牌"
3. 选择新的令牌文件添加

### 令牌文件在哪里

令牌保存在 `~/.aws/sso/cache/`：

```
~/.aws/sso/cache/
├── xxxxxxxx.json  # 令牌文件
├── yyyyyyyy.json  # 另一个令牌
└── ...
```

## 其他问题

### 如何查看请求日志

1. 打开"日志"标签页
2. 查看最近的请求记录
3. 包括时间、路径、模型、状态、耗时

### 如何监控账户状态

1. 打开"监控"标签页
2. 查看服务状态和统计信息
3. 查看配额状态和冷却中的账户

### 配置文件在哪里

- 账户配置: `~/.kiro-proxy/config.json`
- 令牌文件: `~/.aws/sso/cache/*.json`
